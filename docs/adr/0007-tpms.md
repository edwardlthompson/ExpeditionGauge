# ADR-0007: BLE TPMS Advertisement-First Architecture

**Status:** Accepted  
**Date:** 2026-06-29  
**Sprint:** 5b

## Context

Valve-stem BLE TPMS sensors broadcast pressure/temperature in advertisements. GATT connections compete with OBD Classic SPP, external GPS SPP, and up to 4 IMU GATT links.

## Decision

- **Advertisement-first** parsing via modular `TpmsParser` interface
- v1: `BrTpmsParser` for "BR" / UUID 0x27A5 sensors ([omadon/TPMS_BLE_BR](https://github.com/omadon/TPMS_BLE_BR))
- Data published on `TelemetryBus` as `TpmsSnapshot` — does not feed fusion engine
- Gated by `FeatureFlags.tpmsEnabled` (default off)
- Absolute→relative pressure conversion at sea-level default (101.3 kPa / 14.5 psi)

## Consequences

- Minimal BLE connection budget impact
- Phone-only mode unchanged when disabled
- v2: Pecham/Sysgration parsers via GATT on-demand
